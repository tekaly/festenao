# festenao no api context

No backend: the client creates its entities and their access documents
itself (`creatorUserId`), public entities are readable: the rules
(`festenao_firebase` preset `no_api_context`, generated), what the no-api
providers of `festenao_riverpod` run against. `test/project_rules_test.dart`
runs the standalone access groups on the firestore and auth emulators (no
function).
